# powerstore_recycle_bin_config (Resource)

This resource is used to manage the recycle bin configuration of a PowerStore array. The recycle bin allows recovery of intentionally or accidentally deleted volumes and volume groups within a configurable retention period. Use this resource to configure the expiration duration.

We can Read and Update the recycle bin configuration using this resource. We can also import an existing recycle bin configuration from PowerStore array.

> **Note:** Creation and deletion of recycle bin configuration is not supported — the PowerStore system maintains a single configuration instance with ID `"0"`. Requires PowerStore firmware version 3.5.0.0 or later.

## Example Usage

```terraform
# Set recycle bin expiration to 7 days
resource "powerstore_recycle_bin_config" "example" {
  expiration_duration = 7
}

# Disable recycle bin (items expire immediately)
# resource "powerstore_recycle_bin_config" "disabled" {
#   expiration_duration = 0
# }

# Set maximum retention (30 days)
# resource "powerstore_recycle_bin_config" "max_retention" {
#   expiration_duration = 30
# }
```

After the execution of above resource block, recycle bin configuration would have been updated on the PowerStore array. For more information, Please check the terraform state file.

### Required

- `expiration_duration` (Number) Duration in days for items to remain in the recycle bin before automatic purging. Valid range is `0` to `30`. A value of `0` indicates items expire immediately.
